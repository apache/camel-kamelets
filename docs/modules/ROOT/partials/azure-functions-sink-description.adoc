== Azure Functions Sink Kamelet Description

=== Authentication methods

In this Kamelet you should access the function on Azure through a key token in the key parameter.

By default the key is sent as the `code` query parameter of the request. With `keyInHeader` set to true, it is sent in the `x-functions-key` header instead, so the address of the request, which error messages show, does not hold the key:

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:timer-source"
      parameters:
        message: "hello"
      steps:
        - to:
            uri: "kamelet:azure-functions-sink"
            parameters:
              url: "https://azure-function-demo-12234.azurewebsites.net/api/httpexample"
              key: "{{function.key}}"
              keyInHeader: true
----
