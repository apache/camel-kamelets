== Telegram Sink Kamelet Description

=== Telegram Bot Integration

This Kamelet integrates with Telegram's Bot API, enabling automated message sending through a Telegram bot to users,
groups, or channels.

=== Bot Setup

1. Contact @BotFather on Telegram
2. Create a new bot with the `/newbot` command
3. Follow the instructions to set the bot name and username
4. Copy the bot token into `authorizationToken`
5. Add the bot to the group or channel to send to. To send to a person, that person must first start a chat with the
   bot: a bot cannot start a conversation.

=== What It Sends

The Kamelet sends two kinds of messages:

- *Text messages*: by default, the body is sent as the text of the message, as it is. Markdown and HTML are not
  interpreted.
- *Photos*: when the `Content-Type` header is `image/png` or `image/jpeg`, the body is sent as a photo, and the `text`
  (or `ce-text`) header becomes its caption.

=== Choosing the Chat

The chat is taken, in this order, from the `chat-id` header, the `ce-chatid` header, and the `chatId` option. A message
with none of them fails. The ID of a person or a group is a number, negative for a group; a public channel can also be
written as `@channelname`.

To learn the ID of a chat, send a message to the bot and run `telegram-source`: it sets the `chat-id` header of each
message it receives. For the same reason, a route from `telegram-source` to `telegram-sink` answers in the chat the
message came from.

=== Usage Example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:timer-source"
      parameters:
        message: "Order 1234 has shipped."
        repeatCount: 1
      steps:
        - to:
            uri: "kamelet:telegram-sink"
            parameters:
              authorizationToken: "{{telegram.token}}"
              chatId: "123456789"
----

=== Notification Use Cases

Common applications include:

- System alerts and monitoring notifications
- Customer support and engagement
- News and content distribution
- E-commerce order updates
- IoT device status reporting
