== Azure Storage Files Source Kamelet Description

=== Authentication methods

In this Kamelet, you can use these Azure authentication methods:

- Plain Shared Account Key:  `SHARED_ACCOUNT_KEY` (default)
- Azure Identity mechanism:  `AZURE_IDENTITY`
- Shared key credentials: `SHARED_KEY_CREDENTIAL`
- Azure SAS: `AZURE_SAS`

The order of evaluation for `AZURE_IDENTITY` is the following:

 - Enviroment
 - Workload Identity 
 - Managed Identity 
 - Azure Developer CLI 
 - IntelliJ
 - Azure CLI
 - Azure Powershell

For more information, see the https://learn.microsoft.com/en-us/java/api/overview/azure/identity-readme[Azure Identity documentation]

=== Example with Files Moved After Reading

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:azure-storage-files-source"
      parameters:
        accountName: "mystorageaccount"
        shareName: "documents"
        sharedKey: "the-access-key"
        directoryName: "inbox"
        include: ".*\\.csv"
        move: ".done"
        maxMessagesPerPoll: 100
      steps:
        - to:
            uri: "kamelet:log-sink"
----

Only the CSV files are read, at most 100 at each poll. Each file is moved to `inbox/.done` once it has been read, so it
is not read again, also after a restart. Directories whose names start with a dot are never read, also when
**recursive** is true. A path that ends with the name of the file, such as `done/$\{date:now:yyyyMMdd}/$\{file:name}`,
moves the file to a directory of its own day below **directoryName**.

=== Example with Files Remembered Across Restarts

To keep the files on the share and still read each one only once, also across restarts, set **noop** to true and keep
the list of the files read in a file. Declare a `FileIdempotentRepository` bean that writes the list to a file, and give
its name in **idempotentRepository**:

[source,yaml,subs='+attributes,macros']
----
- beans:
    - name: readFiles
      type: "#class:org.apache.camel.support.processor.idempotent.FileIdempotentRepository"
      properties:
        fileStore: "#class:java.io.File('/var/data/read-files.dat')"
- route:
    from:
      uri: "kamelet:azure-storage-files-source"
      parameters:
        accountName: "mystorageaccount"
        shareName: "documents"
        sharedKey: "the-access-key"
        directoryName: "inbox"
        noop: true
        idempotentRepository: "readFiles"
      steps:
        - to:
            uri: "kamelet:log-sink"
----

The file must be on storage that survives a restart of the integration, such as a persistent volume. Without **noop**,
**idempotentRepository** is not used.
