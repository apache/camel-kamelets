== NATS Source Kamelet Description

=== Authentication

The Kamelet has no login options. For a server that needs a user and password, put them in the address in `servers`,
as `nats://user:password@host:4222`. The Kamelet has no TLS options.

=== Output format

The body is the NATS payload, unchanged, as a stream of bytes; it is not turned into JSON, although the `Content-Type`
header is always `application/json`. The `CamelNatsSubject` header is the subject, and the NATS headers of the message
become headers too.

=== JetStream

With `jetstreamEnabled` set to true, the Kamelet reads from the JetStream stream `jetstreamName`, and creates it for
the subject in `topic` when it does not exist. Each time it starts, it reads the stream from the beginning.

=== Usage example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:nats-source"
      parameters:
        servers: "nats://localhost:4222"
        topic: "orders.created"
      steps:
        - to:
            uri: "kamelet:log-sink"
----
