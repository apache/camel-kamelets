== Slack Sink Kamelet Description

=== Team Communication Integration

This Kamelet integrates with Slack, a popular team collaboration and messaging platform. It posts each message as a
text message to a Slack channel, through an incoming webhook.

=== Setup Requirements

1. Create a Slack app in your workspace at https://api.slack.com/apps.
2. On the *Incoming Webhooks* page of the app, turn incoming webhooks on.
3. Click *Add New Webhook to Workspace* and choose the channel to post to.
4. Copy the webhook URL, which starts with `https://hooks.slack.com/services/`, into `webhookUrl`, and the name of the
   same channel into `channel`.

The webhook of a Slack app always posts to the channel it was created for. To post to several channels, create one
webhook per channel and one Kamelet per webhook.

=== Message Formatting

The body of the message becomes the text of the Slack message. The text can use Slack formatting, such as `*bold*`,
`_italic_` and `` `code` ``, and emoji such as `:tada:`. JSON in the body is posted as text, not as a Slack message
structure, so attachments, blocks and interactive elements are not available through this Kamelet.

=== Usage Example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:timer-source"
      parameters:
        message: "The nightly build *failed*."
        repeatCount: 1
      steps:
        - to:
            uri: "kamelet:slack-sink"
            parameters:
              channel: "#alerts"
              webhookUrl: "{{slack.webhookUrl}}"
----

=== Notification Patterns

Common use cases include:

- System alerts and monitoring notifications
- CI/CD pipeline status updates
- Business process notifications
- Customer support escalations
- Automated reporting and metrics
