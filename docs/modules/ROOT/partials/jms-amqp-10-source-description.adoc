== JMS AMQP 1.0 Source Kamelet Description

=== Login and TLS

The Kamelet has no separate options for the login or TLS: they go in `remoteURI`, as settings of the Apache Qpid JMS
client after `?`.

- A login: `amqp://broker.example.com:5672?jms.username=app&jms.password=secret`
- TLS: the `amqps://` scheme, with `transport.trustStoreLocation` and `transport.trustStorePassword` when the broker
  certificate is not trusted by the Java runtime.

=== Output format

The body is text for a JMS text message, bytes for a bytes message, and a Map for a map message. The JMS properties of
the message become headers.

=== Configuration

The Kamelet requires connection parameters for the AMQP 1.0 broker:

- `remoteURI`: the address of the broker, with the login when the broker needs one
- `destinationName`: the name of the queue or topic
- `destinationType`: `queue` (the default) or `topic`

=== Usage example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:jms-amqp-10-source"
      parameters:
        remoteURI: "amqp://broker.example.com:5672?jms.username=app&jms.password=secret"
        destinationName: "my-queue"
      steps:
        - to:
            uri: "kamelet:log-sink"
----
