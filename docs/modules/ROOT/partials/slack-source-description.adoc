== Slack Source Kamelet Description

=== Authentication

This Kamelet requires the OAuth token of a Slack app. You need to create a Slack app and give it the permissions
(scopes) to read channels and their messages.

=== Configuration

The Slack Source Kamelet supports the following configurations:

- **Token**: OAuth token of the Slack app (required)
- **Channel**: the name of the public channel to read, without the leading `#` (required)
- **Server URL**: Slack API server URL (optional, defaults to `https://slack.com`)
- **Delay**: how long to wait between two checks for new messages, in milliseconds or with a unit such as `30s`
- **Natural Order**: whether the new messages of a check are sent oldest first

=== Output Format

The Kamelet outputs each Slack message as JSON text, with fields such as `text` (the content), `user` (the ID of the
author) and `ts` (the time stamp of the message). The message does not say in which channel it was posted.

When it starts, the Kamelet also sends the most recent message already in the channel. After that it sends only the
messages posted since the last check.

=== Setup Requirements

1. Create a Slack app in your workspace at https://api.slack.com/apps
2. Add the necessary OAuth scopes (`channels:history`, `channels:read`, and the others listed for the `token` option)
3. Install the app to your workspace
4. Copy the OAuth token from the *OAuth & Permissions* page of the app

=== Usage Example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:slack-source"
      parameters:
        token: "{{slack.token}}"
        channel: "general"
        delay: 10000
      steps:
        - to:
            uri: "kamelet:log-sink"
----

=== Example Filtering the Messages

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:slack-source"
      parameters:
        token: "{{slack.token}}"
        channel: "alerts"
        delay: 30000
      steps:
        - filter:
            simple: "$\{body} contains 'ERROR'"
            steps:
              - to:
                  uri: "kamelet:log-sink"
----

=== Security Considerations

- Store the Slack token securely as a secret
- Use appropriate OAuth scopes to limit access
- Monitor token usage and rotate tokens periodically
- Consider using Slack's real-time messaging API for high-frequency scenarios
