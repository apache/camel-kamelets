== Kafka-batch-source Kamelet Description

=== Authentication methods

The `saslAuthType` option chooses how the Kamelet logs in to Kafka, as for `kafka-source`. It has
no default and must be set; `NONE` connects with no login and no TLS, as a local Kafka expects.

=== Output format

Each message holds a batch: its body is a List with one entry per record, up to `batchSize`.
Each entry has the value of the record as its body, and the record's key, offset, timestamp and
headers as its headers. To save the position in Kafka only once a batch was handled, set
`allowManualCommit` to true and `autoCommitEnable` to false, and end the flow with
`kafka-batch-manual-commit-action`.

=== Configuration

The Kamelet requires Kafka connection parameters:

- `topic`: The Kafka topic to consume from
- `bootstrapServers`: Comma separated list of Kafka Broker URLs
- `saslAuthType`: How to log in to Kafka, such as `NONE` for a local Kafka
- Security-specific parameters based on the authentication method

=== Usage example

[source,yaml]
----
- route:
    from:
      uri: "kamelet:kafka-batch-source"
      parameters:
        topic: "my-topic"
        bootstrapServers: "kafka-broker1:9092,kafka-broker2:9092"
        saslAuthType: "NONE"
      steps:
        - to:
            uri: "kamelet:log-sink"
----
