== Twitter Search Source Kamelet Description

=== Authentication methods

This Kamelet connects to version 1.1 of the Twitter (X) API with the four keys of an app of the Twitter developer
portal (OAuth 1.0a):

- `apiKey` and `apiKeySecret`: the API key and secret of the app.
- `accessToken` and `accessTokenSecret`: the access token and secret of the account the Kamelet reads with.

All four are on the *Keys and Tokens* page of the app in the developer portal.

=== Output format

Each matching tweet becomes one message. The body is the tweet as JSON text, with its `text`, its `id`, its `lang`,
the time it was created and the `user` who wrote it. The `CamelTwitterEventType` header is `STATUS`.

=== Configuration

The `keywords` option is the search, as you would type it in the Twitter search box. It supports the standard search
operators, such as `OR`, `#hashtag`, `from:user` and `-word`.

The Kamelet searches every 30 seconds. The first search sends up to 5 matching tweets; each later search sends at most
5 tweets newer than the last one it saw.

=== Usage example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:twitter-search-source"
      parameters:
        keywords: "#ApacheCamel"
        apiKey: "{{twitter.apiKey}}"
        apiKeySecret: "{{twitter.apiKeySecret}}"
        accessToken: "{{twitter.accessToken}}"
        accessTokenSecret: "{{twitter.accessTokenSecret}}"
      steps:
        - to:
            uri: "kamelet:log-sink"
----
