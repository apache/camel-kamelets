== SMPP Sink Kamelet Description

=== Message

The message body is sent as the short message text. The recipient is the `CamelSmppDestAddr` header when it is
set, and the `destAddr` option otherwise.

=== Connection

The Kamelet binds to the SMSC when the integration starts, so an unreachable SMSC makes the
integration fail to start, rather than failing each message.

Set `usingSSL` to secure the connection with TLS, where the SMSC supports it.
