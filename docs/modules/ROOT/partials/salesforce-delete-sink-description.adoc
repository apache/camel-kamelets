== Salesforce Delete Sink Kamelet Description

=== Salesforce CRM Integration

This Kamelet integrates with Salesforce CRM to delete records. It provides record deletion through Salesforce's REST
API.

=== Record Deletion

Each message names the record to delete, as JSON text:

[source,json]
----
{
  "sObjectName": "Contact",
  "sObjectId": "003XXXXXXXXXXXXXXX"
}
----

- `sObjectName`: the API name of the kind of record
- `sObjectId`: the Salesforce ID of the record

Because the message decides which record is deleted, place this Kamelet only after a source you trust.

=== Safety and Recovery

Salesforce provides safety mechanisms for deleted records:

- Deleted records are moved to the Recycle Bin
- Records can be restored within the retention period
- Audit trails maintain deletion history

=== Cascade Effects

Salesforce's cascade deletion rules apply: deleting a record can also delete related records, as the relationships of
your org define.

=== API Authentication

The Kamelet logs in through a connected app of your org. Create one in Salesforce Setup, under App Manager, with OAuth
enabled, and copy its consumer key and secret into `clientId` and `clientSecret`. `authenticationType` chooses how the
Kamelet logs in, and which other options it needs.

=== Permission Controls

Respects Salesforce's object-level security settings: the user the Kamelet logs in as must be allowed to delete the
records.
