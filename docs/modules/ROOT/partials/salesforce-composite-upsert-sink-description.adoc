== Salesforce Composite Upsert Sink Kamelet Description

=== Salesforce CRM Integration

This Kamelet integrates with Salesforce CRM using the composite upsert operation of the sObject Collections API.
Several records are processed in a single API call, which reduces API usage.

=== Upsert Operations

Performs upsert (insert or update) operations: a record whose external ID is already in Salesforce is updated, and the
others are created. This avoids duplicate records when the same data is sent again.

=== Input Format

The body is JSON text with a `records` list. All the records are of the kind named by `sObjectName`, and each one holds
the external ID field named by `sObjectIdName`:

[source,json]
----
{
  "records": [
    { "attributes": { "type": "Contact" }, "External_Id__c": "C-1", "LastName": "Lovelace" },
    { "attributes": { "type": "Contact" }, "External_Id__c": "C-2", "LastName": "Hopper" }
  ]
}
----

Salesforce accepts up to 200 records in one call.

=== External ID Matching

Uses an external ID field for record matching, so that records keep the IDs of the system they come from. The field
must be marked as External ID in Salesforce.

=== Error Handling

The Kamelet does not use all-or-none: a record that Salesforce refuses does not fail the message, and the other records
are still saved. The result is a list with one entry per record, in the same order, each with `id`, `success`,
`created` (true for a new record) and `errors`.

=== API Authentication

The Kamelet logs in through a connected app of your org. Create one in Salesforce Setup, under App Manager, with OAuth
enabled, and copy its consumer key and secret into `clientId` and `clientSecret`. `authenticationType` chooses how the
Kamelet logs in, and which other options it needs.
