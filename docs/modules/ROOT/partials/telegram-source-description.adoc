== Telegram Source Kamelet Description

=== Authentication

This Kamelet requires a Telegram Bot token for authentication. You need to create a Telegram bot through @BotFather and
obtain the bot token.

=== Configuration

The Telegram Source Kamelet has one option:

- **Authorization Token**: Telegram bot token (required)

It receives the messages of every chat the bot is in. To keep only the messages of one chat, filter on the `chat-id`
header.

=== Output Format

The Kamelet outputs each Telegram message as JSON text, with the content of the message (`text`), the sender (`from`),
the chat (`chat`) and the time (`date`). The `chat-id` and `ce-chatid` headers hold the ID of the chat.

=== Bot Setup

1. Contact @BotFather on Telegram
2. Create a new bot with the `/newbot` command
3. Follow the instructions to set bot name and username
4. Copy the provided bot token
5. Add the bot to your chat or channel. In a group, the bot receives only commands and replies to it, unless you turn
   its privacy mode off with the `/setprivacy` command of @BotFather.

The Kamelet asks Telegram for new messages with long polling. It does not work while a webhook is set for the bot, and
only one application at a time can read the messages of a bot.

=== Usage Example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:telegram-source"
      parameters:
        authorizationToken: "{{telegram.token}}"
      steps:
        - to:
            uri: "kamelet:log-sink"
----

=== Example with Specific Chat

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:telegram-source"
      parameters:
        authorizationToken: "{{telegram.token}}"
      steps:
        - filter:
            simple: "${header[chat-id]} == '-1001234567890'"
            steps:
              - to:
                  uri: "kamelet:log-sink"
----

=== Message Processing

The kamelet receives all types of Telegram messages including text, photos, documents, and other media. A message
without text, such as a photo, has no `text` field.
