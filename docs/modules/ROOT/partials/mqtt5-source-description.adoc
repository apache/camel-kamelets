== MQTT 5 Source Kamelet Description

=== Authentication

The Kamelet logs in to the broker with `username` and `password`, or without a login when they are not set. For TLS,
use an `ssl://` address in `brokerUrl`. The Kamelet then checks the certificate and the host name of the broker, and
trusts the certificate authorities that Java trusts by default. When the broker has a certificate from a private or
self-signed authority, put the certificate of that authority in a trust store file (JKS or PKCS12) and set
`sslTruststoreLocation` and `sslTruststorePassword`; the Kamelet then trusts the authorities in that file instead.

=== Output format

The body is the MQTT payload, as bytes; it is not turned into JSON. The `CamelMqttTopic` header is the topic of the
message, `CamelMqttQoS` its quality of service, and `CamelPahoMqtt5MsgProperties` its MQTT 5 properties.

=== Configuration

- `topic`: the topic to subscribe to, with the `+` and `#` wildcards
- `brokerUrl`: the address of the broker, such as `tcp://mosquitto:1883`
- `clientId`: the client ID; a unique one is generated when it is not set
- `username` and `password`: the login, when the broker needs one
- `qos`: the highest quality of service to receive messages with, 0, 1 or 2; 2 when it is not set. A message is
  received with the lower of this and the quality of service it was published with, which `CamelMqttQoS` tells
- `sslTruststoreLocation` and `sslTruststorePassword`: the trust store with the certificate authority of the broker,
  for an `ssl://` broker with a certificate from a private or self-signed authority

The Kamelet receives only the messages published while it is connected, plus, when it subscribes, the last retained
message of each matching topic.

=== Usage example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:mqtt5-source"
      parameters:
        topic: "sensors/#"
        brokerUrl: "tcp://mosquitto:1883"
        clientId: "sensor-reader-1"
      steps:
        - to:
            uri: "kamelet:log-sink"
----

=== Example with QoS 1 and TLS

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:mqtt5-source"
      parameters:
        topic: "sensors/#"
        brokerUrl: "ssl://mosquitto:8883"
        clientId: "sensor-reader-1"
        qos: 1
        sslTruststoreLocation: "/etc/mqtt/truststore.jks"
        sslTruststorePassword: "changeit"
      steps:
        - to:
            uri: "kamelet:log-sink"
----
