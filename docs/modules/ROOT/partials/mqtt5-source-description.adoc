== MQTT 5 Source Kamelet Description

=== Authentication

The Kamelet logs in to the broker with `username` and `password`, or without a login when they are not set. For TLS,
use an `ssl://` address in `brokerUrl`.

=== Output format

The body is the MQTT payload, as bytes; it is not turned into JSON. The `CamelMqttTopic` header is the topic of the
message, `CamelMqttQoS` its quality of service, and `CamelPahoMqtt5MsgProperties` its MQTT 5 properties.

=== Configuration

- `topic`: the topic to subscribe to, with the `+` and `#` wildcards
- `brokerUrl`: the address of the broker, such as `tcp://mosquitto:1883`
- `clientId`: the client ID, `mqtt-source` by default; give each running copy its own
- `username` and `password`: the login, when the broker needs one

=== Usage example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:mqtt5-source"
      parameters:
        topic: "sensors/#"
        brokerUrl: "tcp://mosquitto:1883"
        clientId: "sensor-reader-1"
      steps:
        - to:
            uri: "kamelet:log-sink"
----
