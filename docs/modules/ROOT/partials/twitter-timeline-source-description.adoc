== Twitter Timeline Source Kamelet Description

=== Authentication methods

This Kamelet connects to version 1.1 of the Twitter (X) API with the four keys of an app of the Twitter developer
portal (OAuth 1.0a):

- `apiKey` and `apiKeySecret`: the API key and secret of the app.
- `accessToken` and `accessTokenSecret`: the access token and secret of the account the Kamelet reads with.

All four are on the *Keys and Tokens* page of the app in the developer portal.

=== Output format

Each tweet of the account becomes one message. The body is the tweet as JSON text, with its `text`, its `id`, the time
it was created and the `user` who wrote it. The `CamelTwitterEventType` header is `STATUS`.

=== Configuration

The `user` option is the user name (handle) of the account to follow, without the `@`.

The Kamelet checks every 30 seconds. The first check sends the 5 most recent tweets of the account; each later check
sends at most 5 tweets newer than the last one it saw.

=== Usage example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:twitter-timeline-source"
      parameters:
        user: "ApacheCamel"
        apiKey: "{{twitter.apiKey}}"
        apiKeySecret: "{{twitter.apiKeySecret}}"
        accessToken: "{{twitter.accessToken}}"
        accessTokenSecret: "{{twitter.accessTokenSecret}}"
      steps:
        - to:
            uri: "kamelet:log-sink"
----
