== Twitter Directmessage Source Kamelet Description

=== Authentication methods

This Kamelet connects to version 1.1 of the Twitter (X) API with the four keys of an app of the Twitter developer
portal (OAuth 1.0a):

- `apiKey` and `apiKeySecret`: the API key and secret of the app.
- `accessToken` and `accessTokenSecret`: the access token and secret of the account whose direct messages are read.

All four are on the *Keys and Tokens* page of the app in the developer portal. The app needs the permission to read
direct messages; generate the access token again after you change the permissions of the app.

=== Output format

Each direct message becomes one message. The body is the direct message as JSON text, with its `text`, its `id`, the
`senderId` and the `recipientId`. The `CamelTwitterEventType` header is `DIRECT_MESSAGE`.

=== Configuration

The Kamelet reads the direct messages of the account that owns the access token, the ones it received and the ones it
sent. The `user` option is required, but it does not change which messages are read.

The Kamelet checks every 30 seconds. The first check sends every direct message that Twitter still lists, then each
later check sends only the new ones.

=== Usage example

[source,yaml,subs='+attributes,macros']
----
- route:
    from:
      uri: "kamelet:twitter-directmessage-source"
      parameters:
        user: "MyCompany"
        apiKey: "{{twitter.apiKey}}"
        apiKeySecret: "{{twitter.apiKeySecret}}"
        accessToken: "{{twitter.accessToken}}"
        accessTokenSecret: "{{twitter.accessTokenSecret}}"
      steps:
        - to:
            uri: "kamelet:log-sink"
----
